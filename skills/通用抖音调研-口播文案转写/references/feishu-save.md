# 按需保存飞书

仅在用户要求保存、或本次任务已明确包含落表时执行。第一阶段默认对话表格，不自动创建Base或八类视图。

1. 复用本任务用户指定的文档/表格。未指定时，按用户要求的载体选择；“存到飞书”但位置不明时问文档还是多维表格，或使用当前项目已明确的目标。不要从共享Skill的旧 `.base-memory.json` 自动继承客户目标。
2. 使用宿主实际可用的飞书工具；具备 `lark-doc` / `lark-base` 时先读对应技能再操作。没有访问能力时保留对话交付，可另给可导入文件；不能声称保存成功。
3. 只保存必要字段：建议选题、来源标题、链接、作者、视频时长、发布时间、读取时间、原始可见数据、参考类型、内容证据、可借鉴点。第二阶段增加已完成的拆解、原文来源和转写状态；不要求每条都有口播。
4. 表格新增前按视频ID或规范链接去重。不同账号/调研目标的参考理由分开保存，不能因同一视频就吞掉本轮用途；同视频同任务重复运行不重复创建。覆盖已有原文或分析须符合用户授权范围。
5. 写后回读条数与正文，核对来源、未截断、无字面转义换行。失败则说明哪部分未写入，保留本次结果和可续写标识，不重新搜索或转写。

跨客户切换须重新核对保存目标。客户资料、表格标识、转写记录只保存在对应任务环境，不打进通用分发ZIP。
