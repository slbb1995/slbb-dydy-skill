# 读取与证据

## 实际工具优先

先检查宿主提供的搜索、视频读取、字幕和浏览器能力，按工具真实文档调用。优先拿最少必要的结构化字段；不能因工具名称或平台归属推断能力。当前工具只给标题/发布文案时，它不等于视频内容识别。

无适合的专用能力时，用已登录浏览器搜索抖音。第一次调用浏览器前先读当前宿主的浏览器技能/工具文档，不凭记忆猜API。先拿1条候选验证调用成功，再处理下一条；同一方法报错时禁止把其余5条都重复一遍。豆包工作旧环境曾使用 `computer_use_tool(plane="bu")` 和 `bu.download`；这是历史适配信息，仅在当前宿主确实暴露这些工具及签名时使用，不向其他宿主照搬。无浏览器或登录受阻就交代，不编造搜索结果。

## 详情读取的最短路径

抖音搜索可用宿主video_search初筛。若其缺duration，详情页优先读取播放器可见的“当前位置 / 总时长”，不用先尝试复杂JS。豆包工作本次实测可用的读取组合为 `bu.navigate`、`bu.wait_for_load`、`bu.get_page_text`，仍以当次浏览器Skill签名为准；不要用未定义的 `bu.goto`。先单条成功，不整批试错。加载已完成时不额外固定sleep；当前/总时长尚未出现才短等一次。

身份和时长确认后，用当前浏览器文档支持的截图/视频查看方法实际看产品画面。保留简短观察方法与区间；第一阶段只确认画面与本次方向相关，详细镜头结构留到第二阶段。作者信息截断时定向补读作者区域，不把“未读到”当作者名。

## 页面身份与数据

- 搜索地址可用 `https://www.douyin.com/search/{URL编码关键词}`，详情规范链接为 `https://www.douyin.com/video/{已核验ID}`。
- 先读限定范围卡片文本，只有定位不清时才取整页快照。页面未加载时适当等候后重读一次；不要固定每步睡眠或无限滚动。
- 页面可能暴露 `waterfall_item_{video_id}`，也可能没有；这只是定位线索。卡片DOM顺序不保证等于视觉顺序，不能按序号把不同卡片标题与ID拼接。
- 打开详情或播放器后，将实际作者、标题/文案、可见时长和画面同候选核对。核对失败先修正ID；仍不确定就待核验。切换模态播放器可能换视频，读取数据与下载前均确认当前身份。
- 发布文案、画面文字、字幕、口播是不同来源。内容判断基于实际播放/可用视频理解结果或已验证对应的字幕，不据标题臆测剧情、开头或镜头。第一阶段可抽看开头、关键段、结尾；标明观察范围，不冒充完整观看。
- 视频总时长以当前视频播放器/工具明确返回的duration为准，搜索卡片可初筛但必要时到详情核对。记录原始时长与秒数；不得把当前位置、字幕末尾时间或发布文案里的“60秒”当总时长。超90秒排除；未知时长标待核验，不进入推荐计数，不下载或提交ASR来探测。
- 数据读不到用空值；点赞/收藏等保留原显示值，转换“万”后不能伪装精确计数。保留读取时间与来源，未知发布时间不猜测。
- 评论使用当前授权工具或自然渲染页面；不猜测、重放隐藏评论接口，也不绕过登录与访问限制。

## 精简续跑记录

当前任务保存紧凑摘要即可：主题/目的/明确限制、业务来源、已用关键词、已查视频ID、入选候选及证据位置、实际预算使用、选定视频与ASR任务ID。只保留必要片段，不重复携带完整DOM、全部评论或企业原文。

用户要求跨会话续跑，才把摘要保存到本次授权工作目录并返回路径；不写共享Skill目录或复用其他客户的历史状态。


## 候选检查器输入

只记录拟入选的少量候选，禁止把搜索摘要的推测升级成观察事实。例中字段说明不是待填成事实的示例内容：

```json
{"candidates": [{
  "video_id": "已核验的数字ID",
  "url": "https://www.douyin.com/video/已核验的数字ID",
  "title": "原视频标题",
  "author": "实际作者",
  "identity_verified": true,
  "duration_seconds": null,
  "duration_source": "player或tool_duration",
  "duration_evidence": "实际播放器总时长显示或工具duration字段",
  "content_source": "video_observation或verified_subtitles或video_understanding",
  "observation_method": "browser_screenshot或video_reader或subtitle_read",
  "observation_scope": "真实截图时间点/已看区间及工具来源，或完整字幕核对范围",
  "content_evidence": "实际看到的片段/对应时间点；不能复制标题充当证据",
  "suggested_topic": "建议本企业做的题目"
}]}
```

只有已核验时才填写数值和true；未核验保持null/false，检查器会给出缺口。无须在用户结果中展示JSON。保留检查器输出以便本任务回查。
