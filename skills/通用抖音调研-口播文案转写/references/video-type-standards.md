# 视频类型判断

这是内部判断提示，允许混合形式。不要让用户先选八大类，也不设置跨行业统一的点赞、天数或咨询人数门槛。

| 形式/目的 | 优先观察 | 何时需要评论 |
|---|---|---|
| 获客 | 客户具体问题、服务适配条件和咨询动作 | 要声称有咨询迹象时必须核验 |
| AI创意 | 画面机制、情绪、创意与内容目的 | 要声称观众理解或共鸣时 |
| 广告/品牌 | 产品怎样进入场景、记忆点 | 要声称产品反馈或购买意向时 |
| 口播 | 开头、观点推进、证据、结尾 | 要评价观众反应时 |
| IP | 人物经历、判断或专业能力 | 要声称人物认同或信任时 |
| 知识/干货 | 解决的问题、步骤、当前适用性 | 需要判断观众实际疑问时 |
| 种草/测评 | 体验、对比、选购依据与人群适配 | 要声称购买需求或真实使用反馈时 |
| 剧情/娱乐 | 人物关系、冲突、转折、情绪与植入 | 要声称笑点、共鸣、催更反应时 |

## 两种参考价值

传播参考：列出实际数据及比较口径。例如“本轮已读的同题视频中收藏较突出”，仅在确有同口径样本时使用。不同类型、发布时长、粉丝体量会影响比较；没有对应数据不计算互动率或跨行业综合分。数据大不证明自然流量、成交或可复制效果。用户未指定爆款门槛时，不另外搜索大量样本只为建立排名。

适配参考：至少说清一项本次需求的对应关系和一项可迁移做法。高互动但跑题不能靠传播标签凑数；低互动但表达适合可以保留为适配参考。两种价值不要求各占几条；没有可证实传播表现的结果就如实说明。

## 咨询证据

只计已观察到的、去重的具体需求表达，如询价、采购、预约、合作、适配条件。排除作者回复、推广、抽奖和领资料口令。报告“当前读到的评论中观察到……”及范围，不能把样本外推为整条视频线索总量，更不能说已经成交。

无评论可读时，可保留有内容证据的“获客表达参考”，但不称“已验证获客案例”。单条作品表现也不能证明整个账号长期成功。
